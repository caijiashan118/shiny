# AI城建系统

一个基于Flask的智能城市建设管理系统，包含基础数据管理、数据可视化和智慧报表生成三大核心模块。

## 系统功能

### 1. 基础数据模块
- **项目基本信息表**：管理项目的基本信息，包括项目名称、编码、建设单位、主管部门、立项时间、概算金额、开工完工时间、项目状态等
- **资金安排表**：管理项目的资金安排信息，包括资金性质、批复金额、经办人、经办处室等
- **数据透视表**：按项目编码和资金性质生成统计报表，支持债券资金合计计算
- **Excel导入导出**：支持项目基本信息和资金安排数据的Excel文件导入导出

### 2. 数据可视化模块
- **项目状态分布图**：饼图展示项目状态分布情况
- **资金性质分布图**：柱状图展示各类资金性质的使用情况
- **投资趋势图**：折线图展示项目投资的时间趋势

### 3. 智慧报表生成模块
- **项目概览报表**：生成项目基本信息和资金安排概览
- **资金分析报表**：分析各类资金使用情况和分布
- **趋势分析报表**：分析项目投资和建设趋势

## 技术架构

- **后端**：Flask + SQLite
- **前端**：Bootstrap 5 + Chart.js
- **数据处理**：Pandas + OpenPyXL
- **数据库**：SQLite

## 安装和运行

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动系统
```bash
python run.py
```

或者直接运行：
```bash
python app.py
```

### 3. 访问系统
打开浏览器访问：http://localhost:5000

## 数据字段说明

### 项目基本信息表字段
- 项目名称：项目的具体名称
- 项目编码：项目的唯一标识码
- 建设单位：负责项目建设的单位
- 项目主管部门：项目的主管部门
- 立项时间：项目立项的日期
- 概算批复金额：项目概算批复的金额（万元）
- 预计开工时间：项目预计开工的日期
- 预计完工时间：项目预计完工的日期
- 项目状态：在建、续建、完工、暂停

### 资金安排表字段
- 项目名称：关联的项目名称
- 项目编码：关联的项目编码
- 建设单位：关联的建设单位
- 项目主管部门：关联的项目主管部门
- 概算批复金额：项目的概算批复金额
- 资金批复金额：本次资金批复的金额（万元）
- 批复日期：资金批复的日期
- 资金性质：一般债券、专项债券、中央综合财力、土地出让金、中央预算内投资、中央补助、省级补助
- 经办人：资金安排的经办人员
- 经办处室：资金安排的经办处室

## API接口

### 数据获取接口
- `GET /api/projects` - 获取项目基本信息列表
- `GET /api/funds` - 获取资金安排列表
- `GET /api/pivot` - 获取数据透视表数据

### 数据导出接口
- `GET /api/export/projects` - 导出项目基本信息Excel
- `GET /api/export/funds` - 导出资金安排Excel
- `GET /api/export/pivot` - 导出数据透视表Excel

### 数据导入接口
- `POST /api/upload/projects` - 上传项目基本信息Excel
- `POST /api/upload/funds` - 上传资金安排Excel

## 使用说明

1. **查看数据**：在基础数据模块可以查看项目基本信息和资金安排数据
2. **导入数据**：点击"导入Excel"按钮可以上传Excel文件导入数据
3. **导出数据**：点击"导出Excel"按钮可以下载Excel格式的数据文件
4. **数据透视**：在数据透视表标签页可以查看按项目编码和资金性质的统计信息
5. **可视化分析**：在数据可视化模块可以查看各种图表分析
6. **报表生成**：在智慧报表模块可以生成各种分析报表

## 注意事项

1. Excel导入文件必须包含所有必要的列
2. 项目状态只能输入：在建、续建、完工、暂停
3. 资金性质只能输入：一般债券、专项债券、中央综合财力、土地出让金、中央预算内投资、中央补助、省级补助
4. 项目编码在系统中必须唯一
5. 建议定期备份数据库文件
