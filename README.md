# AI城建系统

模块：基础数据、数据可视化、智慧报表生成。

功能要点：
- 基础数据：项目基本信息表、资金安排表、重点项目清单；支持 Excel 导入/导出；按项目编码联通。
- 数据可视化：按资金性质合计、项目资金 Top 20、重点项目对比。
- 智慧报表生成：按项目编码生成资金安排透视表；一般债券/专项债券单独求和并生成债券资金合计；支持导出。
- 一键模拟数据（200 项目 + 1000 资金安排）。

## 环境与启动

1. 安装依赖
```bash
pip install -r requirements.txt
```

2. 启动应用
```bash
streamlit run app.py
```

3. 使用说明
- 侧边栏点击“生成模拟数据”可快速生成演示数据。
- 基础数据页可导入/导出 Excel：需包含“项目基本信息”和“资金安排”两个工作表。
- 智慧报表页可查看并导出透视表（按项目编码 × 资金性质）。

## 数据存储
- CSV 存放于 `data/` 目录：`projects.csv`、`fundings.csv`、`key_projects.csv`。

## 字段规范
- 项目基本信息表：项目名称、项目编码、建设单位、项目主管部门、立项时间、概算批复金额、（预计）开工时间、（预计）完工时间、项目状态（在建/续建/完工/暂停）。
- 资金安排表：项目名称、项目编码、建设单位、项目主管部门、概算批复金额、资金批复金额、批复日期、资金性质（一般债券、专项债券、中央综合财力、土地出让金、中央预算内投资、中央补助、省级补助）、经办人、经办处室。
